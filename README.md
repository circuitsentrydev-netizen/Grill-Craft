# Grill Craft

Responsive, static Vite website for Grill Craft's flame-grilled chicken specials.

## Deploy to Vercel

Import this repository with its root directory set to the repository root. Vercel reads the included `vercel.json` for the build command and output folder.

To enable WhatsApp ordering, add `VITE_WHATSAPP_NUMBER` in the Vercel project environment variables. Use the business number in international format with digits only (no `+`, spaces, or punctuation), then redeploy. Until it is set, order buttons explain that ordering is not configured.
